# ADR 0001: The language model explains; it never decides

Status: accepted, 16 Nov 2026

## Context
A decline decision moves money and incurs scheme fees. A wrong retry of a never-retry code
costs fees and harms approval rates. Language models are not deterministic and cannot be
unit-tested to the standard of a payment rule.

## Decision
- A pure, deterministic rules engine (`src/core/engine.ts`) makes every decision: retry or
  not, when, through which PSP, refresh the credential, ask the customer or stop.
- Llama 3.3 70B (fp8-fast) on Workers AI only answers operator questions. It calls six
  read-only tools over the ledger and has no tool that can change anything.
- Every figure the model can quote is computed and formatted in code (`src/worker/chat.ts`,
  `src/worker/format.ts`). The system prompt tells it to quote figures exactly. If the model
  answers without calling a tool, the code makes it call the summary tool first.
- Customer messages are templates chosen by code, not text generated by the model.

## Consequences
- Decisions are reproducible and covered by a table of more than 50 decline cases.
- Chat answers can still be worded badly or miss a nuance. They cannot change an outcome.
- The functional tests check that chat answers name only allowed read-only tools.
